# Pokémon Canvas: each Pokémon's synthetic ability (the Ability Synthesizer, in the basement).
#
# One line per group:   SPECIES (without SPECIES_), space-separated : Ability name : why
# A form not listed takes its species' first form's (Pikachu's caps, Unown's letters, Vivillon's
# patterns...). Always an existing ability; meant to be a little better than what the Pokémon has,
# never game-breaking. "sidegrade" = its own ability is already one of the best it could have, so
# this is an alternative rather than an upgrade. "flag" = its own ability drives a form change
# (Stance Change, Schooling...) that the synthetic ability would replace.
#
# Built into src/data/pokemon/synthetic_abilities.h and the review list by
# tools/gym_hack/build_synthetic_abilities.py.
